# Demo video script

File: `fleek-route-economics-lab-demo.mp4`, delivered separately (not committed). Vertical 1080×1920, 30 fps, 85.6 s, H.264 + AAC.

Capture: the real built app at **desktop width** (1366 CSS px browser viewport, 2428 px tall to match the 9:16 frame, 1.75× device scale). Wide shots show both route cards side by side in one view; guided zooms then crop into one region (up to 2.2×) so the text can be read in a vertical frame. The phone layout was not used. Cursor, click ripples and captions are added afterwards on top of the real screenshots. Narration uses a free offline text-to-speech voice with no paid service. Captions show whole phrases, timed in proportion to each narrated line.
