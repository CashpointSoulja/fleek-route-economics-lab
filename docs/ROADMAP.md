# Roadmap (proposed, TO TEST)

1. **Actuals loop:** import pilot-lot actuals (yield, returns, freight) and show assumption error per input.
2. **N routes and categories:** compare more than two routes; per-category grading yield.
3. **Evidence attachments:** attach the quote/broker note file to an input and require reviewer sign-off on gate inputs.
4. **Tiered costs:** freight by container fill, minimum charges, duty relief scenarios entered by a broker.
5. **Shared decision log:** server-backed, append-only, with reviewer identity.
6. **Demand evidence slot:** a separate, explicitly sourced buyer-demand input, kept apart from the "what it would take" scale view.
